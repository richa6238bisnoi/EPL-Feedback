# Project Structure

```text
giftogram-repository/
├── CONTRIBUTING.md
├── PROJECT_STRUCTURE.md
├── README.md
├── package.json
├── public/
│   ├── index.html
│   └── manifest.json
└── src/
    ├── App.css
    ├── App.js
    ├── App.test.js
    ├── index/
    │   ├── index.css
    │   └── index.js
    └── components/
        ├── ExpenseForm.css
        ├── ExpenseForm.js
        ├── ExpenseList.css
        ├── ExpenseList.js
        ├── Header.css
        ├── Header.js
        ├── Receipt.css
        └── Receipt.js
```

The requested `src_components_*` names are represented by the corresponding files inside `src/components/`, which follows the standard Create React App structure and keeps component imports clean.
