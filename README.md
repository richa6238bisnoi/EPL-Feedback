# EPL Feedback

## Description
EPL Feedback is a comprehensive platform engineered specifically for English Premier League enthusiasts and matchday travelers. Designed to streamline the fan experience, the application allows supporters to submit detailed stadium and matchday feedback while maintaining a precise log of match-related expenses. Whether traveling away or attending home fixtures, fans can record ticket purchases, merchandise, concessions, and transit costs in real time. The app generates transparent receipt summaries to keep matchday budgets accountable and organized. EPL Feedback bridges the gap between stadium fan engagement and financial clarity, empowering supporters to share voice-driven feedback on match atmospheres, stadium accessibility, and ticket value. By organizing expenses and feedback into unified digital receipts, users can review historical costs across the season, analyze spending trends per club, and contribute valuable community insights. Built with modern web standards, EPL Feedback provides a responsive, intuitive interface accessible across mobile and desktop devices for matchday convenience.

---

## Features
- **Matchday Feedback Submission**: Rate stadium atmosphere, amenities, and overall experience.
- **Expense & Receipt Tracking**: Seamlessly record food, tickets, travel, and merch costs per fixture.
- **Dynamic Receipt Summary**: View an auto-calculated itemized breakdown of expenses.
- **Interactive UI**: Clean, responsive, and football-focused dashboard design.
